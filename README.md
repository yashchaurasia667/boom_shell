## Keybinds
```
Mod + Shift + W -> wallpaper picker
Mod + Shift + Q -> power menu
```

## How to install

```bash
$ git clone https://github.com/yashchaurasia667/boom_shell.git
$ cp -r ./boom_shell/* ~/.config/quickshell/
$ qs & disown
```
